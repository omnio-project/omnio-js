## 前提 [#prerequisites]

- Node.js 24 以降を想定しています。
- TypeScript の基本的な文法を理解していることを前提とします。
- 最初の埋め込みでは、モデルのダウンロードが発生します。ネットワークに接続できる環境で実行してください。
