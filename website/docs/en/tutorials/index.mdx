## About the tutorials [#about-tutorials]

Tutorials are learning material. You follow them from start to finish, run the code, and see the results. They prioritize a working example over complete conceptual explanation.

If you are new to Omnio-js, work through them in order.

<CardGroup cols={2}>
  <Card title="Save your first object" href="/tutorials/first-objects" icon="package-plus">
    Build an Omnio instance and save, read, search, and delete an object.
  </Card>
  <Card title="Try semantic search" href="/tutorials/semantic-search" icon="search">
    Search by description and narrow the results with tags.
  </Card>
</CardGroup>

## Prerequisites [#prerequisites]

- Node.js 24 or later is assumed.
- You should be comfortable with basic TypeScript.
- The first embedding downloads a model. Run the tutorials in an environment with network access.

## Next steps [#next]

After the tutorials, look for the task you need in the [how-to guides](/how-to). Exact API details are in the [reference](/reference).
